# Getting started with VSP Codex

Run `vsp-codex` in any repository to start the TUI. VSP Codex reads configuration from `~/.vsp-codex`, initializes the VSP Provider with Base URL + API Key, and can browse shared Codex sessions with `vsp-codex resume --all`.

See [VSP Codex 用户指南](vsp-codex.md) for the local fork behavior.
